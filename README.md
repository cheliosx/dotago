# Dota Heroes · 冰封王座

基于 **Godot 4.7.2** 的回合制 4X 策略 + 战棋 RPG 可玩原型。
世界、英雄、兵种、法术与装备取材自 Dota1；美术与叙事基调为暗黑奇幻（魔兽争霸 / 魔兽世界式）。
面向 iPad 横屏的触控操作设计，同时在桌面端可直接用鼠标游玩。

> 这是个人原型，Dota 相关名称与设定归 Valve / Blizzard 所有，仅用于非商业学习与演示；正式发布需替换自有 IP 内容。

## 一、怎么运行

1. 打开 Godot **4.7.2**（本机已装：`C:\Users\PC\Desktop\Godot_v4.7.2\Godot_v4.7.2-stable_win64.exe`）。
2. `导入 / Import` → 选择本目录下的 `project.godot` → 打开项目。
3. 按 **F5**（或点右上角播放）运行。首次打开编辑器会自动导入字体与贴图，等几秒即可。

命令行运行（无需编辑器）：

```bash
"C:/Users/PC/Desktop/Godot_v4.7.2/Godot_v4.7.2-stable_win64_console.exe" --path E:/godotProject/dotago
```

自检脚本（无头模式，验证建图 / 移动 / 建造 / 升级 / 战斗 / 回合结算全链路）：

```bash
"C:/Users/PC/Desktop/Godot_v4.7.2/Godot_v4.7.2-stable_win64_console.exe" \
  --headless --path E:/godotProject/dotago --script res://tools/selftest.gd
```

`tools/capture.gd` 会生成 `shot_title.png` / `shot_world.png` / `shot_battle.png` 三张真实运行截图。

## 二、操作

| 场景 | 操作 |
| --- | --- |
| 大地图 | 点击**金色高亮六边形**移动英雄（消耗移动力）；点击己方城镇进入管理；点击敌方英雄 / 野怪营地 / 有守军的矿场发起战斗 |
| 顶栏 | `城镇` `图鉴` `英雄` `结束回合 ▶` |
| 战斗 | 点击蓝色高亮格移动，点击敌军攻击；`防御` `等待` `自动战斗` `撤退`；右侧点法术名进入施法模式再点目标 |
| RPG | 英雄面板可加技能点、穿脱装备、查看法术书；城镇可建造、募兵、招英雄、买装备、换资源 |

**胜利条件**：占领天灾军团全部城镇并击败其所有英雄。

## 三、已实现的系统

### 战略层（4X，回合结算）
- 16×11 六边形世界地图（odd-r 偏移坐标）、7 种地形与不同移动消耗、战争迷雾（已探索 / 当前可见两级）
- Dijkstra 移动力范围高亮与路径回溯；英雄每日移动力由「后勤学」与靴子类装备加成
- 8 座矿场（金币 / 木材 / 秘银 / 水晶 / 灵魂精华）、4 座城镇、4 处野怪营地、4 处宝箱
- 9 种建筑：城镇大厅、兵营、射手营地、魔法塔、酒馆、铁匠铺、市场、城墙、资源仓库
- 每日收入结算、魔法值回复、每 3 天随机剧情事件、AI 英雄抢矿与袭扰补给线、胜负判定

### 战斗层（六边形战棋）
- 13×9 战场，按兵种**速度**排序的行动队列，等待 / 防御 / 反击 / 障碍物
- 近战、远程（贴身伤害减半）、伤害随部队数量与英雄攻防结算、顶部单位血量池模型
- 英雄作为指挥官：每回合可施放 1 次法术（冰霜新星 / 龙破斩 / 神灭斩 / 奥术弹 / 神圣之光 / 霜甲术 / 死亡脉冲 / 影压 / 法力损毁）
- 敌方 AI 自动寻敌、走位与射击；`自动战斗` 可一键快速结算（适合 iPad 上碎片时间）
- 战后经验、战利品、装备掉落、部队战损与城镇 / 矿场归属结算

### RPG 与叙事
- 8 名 Dota1 英雄（水晶室女、敌法师、月之骑士、秀逗魔导师、骷髅王、影魔、巫妖、斧王），16 种兵种
- 等级 / 经验 / 攻防力量知识四维 / 7 种可升级技能 / 6 格装备栏 / 13 件 Dota 装备 / 法术书 / 酒馆招募第二英雄
- 序章叙事、6 条世界观词条、英雄传记、战役日志、战术手册

### 美术
- 全代码绘制的暗黑奇幻 UI（石纹面板、金边、六角暗纹、世界之树与冰封王座剪影、星尘、颗粒噪点与暗角贴图）
- 内嵌 **Noto Sans SC**（OFL 授权）中文字体，避免中文显示为方块
- `canvas_items + expand` 自适应缩放，触控与鼠标通用，按钮尺寸适配手指

## 四、导出到 iPad（重要）

Godot 的 **iOS 导出必须在 macOS + Xcode 环境完成**，Windows 上只能开发与桌面测试，无法直接产出 `.ipa`。流程：

1. 在 Godot 编辑器 `项目 → 安装导出模板`，下载对应 4.7.2 的 iOS 模板（Mac 上）。
2. `项目 → 导出 → 添加 iOS 预设`，填写 Apple Team ID / Bundle Identifier；方向选 **Landscape**，勾选需要的设备族。
3. 导出 `.xcodeproj` 后用 Xcode 签名并部署到 iPad（真机需要 Apple Developer 账号）。
4. 项目已开启 `emulate_mouse_from_touch`，所有点击逻辑自动兼容触摸。

## 五、目录结构

```
project.godot              # 项目配置 / autoload / 横屏与缩放
scenes/Main.tscn|gd        # 根控制器：视图切换、弹窗、提示、背景绘制
autoload/Game.gd           # 全局状态：地图生成、寻路、回合、经济、AI、战斗结算
autoload/DB.gd             # 静态数据表：英雄/兵种/法术/技能/装备/建筑/剧情
core/Hex.gd                # 六边形数学（偏移↔轴向、距离、邻居、洪水寻路）
core/UI.gd                 # UI 皮肤与控件工厂
views/TitleView.gd         # 标题 + 英雄选择 + 序章
views/WorldView.gd         # 战略大地图（含自定义绘制与点击命中）
views/TownView.gd          # 城镇经营
views/HeroView.gd          # 英雄 RPG 面板
views/BattleView.gd        # 战棋战斗（含 AI 与法术）
views/CodexView.gd         # 世界观图鉴 / 日志 / 战术手册
assets/fonts/              # Noto Sans SC（OFL）
assets/img/                # 程序化生成的噪点与暗角贴图
tools/gen_textures.py      # 贴图生成脚本（纯标准库，无需 Pillow）
tools/selftest.gd          # 无头集成测试
tools/capture.gd           # 运行截图脚本
```

# 2026-11-18

## 主地图交互：点击 / 拖动分离 + 到达事件（第七轮）

**需求原话**：区分点击和拖动，点击是查看，拖动是拖动地图，不需要右键移动；
移动到目标位置后判定事件，有事件就弹菜单（金矿问是否占领，怪物问是否攻击）。

**实现**

- `core/View3DCtrl.gd` 新增两个手势开关：`drag_commands`（单指拖动是否下指令）、
  `right_click_commands`（右键是否下指令）。默认 true（战场行为不变），主地图 `_ready()` 里都置 false。
- `views/WorldMapView.gd`：
  - 点击英雄 → 查看面板；点击地点 → 距离 > 9 米时「看情报 + 自动寻路过去」，已在旁边则直接弹事件菜单；
    点击空地 → 关面板 + 走过去。
  - 到达到判定：`_process` 里路径排空 → `_on_hero_arrived()`，优先用 `pending_poi`，
    否则落点 6.5 米内找最近地点 → `_ask_poi()` → `_event_popup()`（自建 modal，主按钮 + 稍后再说）。
  - 类型分支：金矿无守军 → 占领 / 有守军 → 发起战斗；营地 → 攻击怪物；酒馆 / 铁匠铺 → 进入；
    我方城镇 → 进入城镇；敌方城镇只提示。
  - 目标落点标记：地面半透明光斑 + 金环（TorusMesh），呼吸缩放，到达即清。
  - 拾取阈值 90px → 58px（POI）、70px → 52px（英雄），并加「射线落点距建筑 4.5 米」兜底。

**踩坑**

- 验收脚本里 `var v := _view()` 写在 `match` 之前，`G.goto("world")` 同帧拿到的还是旧视图，
  `v.get("pois")` 返回 null（报「Unable to iterate on object of type 'Nil'」）。视图切换后要下一帧再取。
- 屏幕半径 90px 太宽，点建筑旁边空地会被判成点建筑（测试里点空地却弹面板）。缩小 + 世界距离兜底解决。
- `_on_hero_arrived` 里要先 `_close_event()`，否则到达时若已有菜单开着，`_event_popup` 会因
  「已存在就 return」而丢掉事件。

**当前约定**

- 主地图：点 = 行动，拖 = 移镜头，没有右键指令；战场：点 = 查看，右键 / 按住拖动 = 指令。
  两套手势靠 `View3DCtrl` 的两个开关区分，不要再往各视图里写手势代码。
- 新地图没有战争迷雾，AI 英雄仍只是数据（守在寒骸堡），这两条还欠着。

## 第八轮：多方势力对抗 + 驻军 + 撤退

**需求原话**：玩家出生在一个营地，地图外面有很多营地，每个营地是一方势力，最终消灭所有势力；
占领金矿、伐木场产出金币和木头；用金币和木头招募英雄与士兵；据点可派兵驻守；
被进攻时可以选择撤退，撤退后丢失金矿和伐木场的产出。

**落地**

- `Game`：新增 `factions`（5 方）、`bases`（营地）、`pending_defenses` / `awaiting_defense`。
  `build_map_world()` 递归扫 `kind == "base"` 的 POI → `init_factions()`；
  `FACTION_HERO_DEFS` 给每方指定统帅（scourge=lich / claw=axe / iron=skeleton_king / ash=nevermore）。
- `create_hero(..., fac)` 支持覆盖势力；AI 英雄 faction 用势力 id，兵种池走 `DB.RECRUITS[id]`。
- 经济：`income()` 按 owner 结算；营地 +600 金 +6 木，伐木场 20 木/天（`DB.RES.wood.daily` 4→20）。
- 招募：`recruit(site_id, ...)` 支持城镇与营地，成本 `unit_cost()` = 金 + ceil(金/200) 木；
  `hire_hero()` 2500 金 + 8 木，营地不需要酒馆。
- 驻军：`garrison_add / garrison_take / garrison_strength`；主地图面板「驻守 / 调兵」弹窗，
  每支部队 1/5/全部。
- 回合拆分：`end_turn()` = `ai_phase()` → 有 `pending_defenses` 就 `defense_prompt.emit()` 等玩家；
  `resolve_defense(retreat)` 逐条处理，队列空了才 `settle_turn()`（天数/收入/回魔/存档）。
- AI：`_ai_hero_turn` 每回合推进 14 米（`_ai_advance` 用 24 方向挑最朝向目标且可走的方向），
  抵达 6.5 米内 `_ai_attack_site()`；打玩家据点挂起、打 AI 据点按战力结算；每 3 天补兵。
- 胜负：`faction_alive()` = 有营地或有活英雄；全灭 → win；玩家无营地且无英雄 → lose。
- 视觉：`Poi._build_base()`（栅栏/帐篷/篝火/阵营旗）、`_build_lumber()`（工棚/木堆/锯木架）；
  `_sync_poi_owners()` 据点易主后重建模型；地图显示所有英雄（敌方红名 + 阵营色底座）；
  AI 行军用 lerp 插值；`cam_max = 88` 可以拉远看全图；水 plane 放大到 2.6 倍避免地图边缘黑边。

**踩的坑**

- `site_by_id()` 最初只查 towns/bases，`_apply_defense` 对矿场直接 return，表现为「点了撤退但归属没变」。
- `_garrison_modal` 卡片漏加兵种名 label，只显示 1/5/全部 按钮。
- `_spawn_heroes` 原来跳过 `is_ai`，导致地图上完全看不到敌军。
- 开局出生点离营地 12+ 米，招募提示「英雄必须驻扎在据点附近」——改成出生在营地门口（+7 米），阈值 16 米。
- 自己据点点击原本会弹「是否进入」菜单，多一步；改为自己人据点直接开面板，敌对据点才弹进攻确认。

**当前约定**

- 势力 id 就是 `owner` 字符串，玩家 = `sentinel`；判断归属一律用 `String(ref.owner) == Game.faction`，
  不要再用 `poi.owner_id`（那是场景初始值，占领后不会变）。
- 结束回合如果有待处理的防守，`turn_busy` 保持 true，必须先 `resolve_defense()` 才会 `settle_turn()`。

## 第九轮：地图文字加粗与描边

- `UI.world_font()`：`FontVariation` + `variation_embolden = 0.9`，缓存复用（Noto Sans SC 只有一个字重）。
- `View3DCtrl.add_label` / `Poi._label`：font_size ×2、pixel_size 减半（纹理更细、世界尺寸略大）、
  outline_size 5→14（近纯黑）、`alpha_cut = OPAQUE_PREPASS`、`texture_filter = LINEAR`（关 mipmap）。
- 大地图名牌 `no_depth_test = true` + `render_priority = 2` 穿树可见；
  `add_label(..., ignore_depth)` 让战场保持正常深度测试。
- `WorldMapView._update_label_scale()`：按 `dist/46` 缩放 pixel_size（0.85~1.95），
  拉远看全图地名不缩成蚂蚁。`_label_dist` 做 0.5 米阈值，避免每帧全量遍历。
- 英雄名 size 40→50、y 1.75→2.0。

**修正（同日）**：描边 14px 对 84 号字形太粗，视觉上像「黑底黑边」。改为
「浅色字 + 深色细边」——`Poi._label` 里 `modulate = col.lightened(0.55)`，
`outline_size = maxi(6, round(font_size * 0.11))`（约 2 屏幕像素）、`outline_modulate = Color(0,0,0,0.98)`；
英雄名改成玩家 `#eaf4ff` / 敌方 `#ffe2da`；顶部 2D 提示的描边 5→3。
营地副标题（势力名）从 y 6.6 挪到 8.3，避免被旗杆与帐篷挡住。

**再修正（同日）**：用户截图反馈「描边很奇怪、看不清」。根因有两个：
1. `alpha_cut = OPAQUE_PREPASS` 与 Label3D 描边冲突，字形被啃成镂空轮廓 —— 去掉。
2. 地名 `pixel_size` 0.0076 在 46 米视距下只有 13 屏幕像素，笔画压碎成噪点 —— 提到 0.0132（23px）。
试过「底层黑粗描边 + 上层白字」双层方案：两层共面 z-fighting，截图变黑白噪点，**不要再用**。
最终：单层 Label3D + 内置 `outline_size = fs * 0.105`（约 2px）+ 统一浅暖白 `#fff6e8`，
字色不再跟资源色（白岩矿场上看不清）。`display_name()` 也去掉重复的「（金币矿）」，矿场只显示标题。

**第十轮：势力配色**。`Poi._owner_color() / _name_color() / _flag()`；营地帐篷、城镇主副楼与屋顶、
领地基座按势力色染；矿场/伐木场插归属旗（无主为中立灰）；地名我方 `#d8efff`、无主 `#fff6e8`、
敌对 `#ff7a65`；英雄名敌方 `#ff6b57`，脚下加常驻阵营色细环。

**第十一轮：点击不再误触行走**。用户反馈「点建筑角色却走过去」。改为单击地点只开面板，
移动只能来自：点空地 / 面板「前往 xx 米」按钮 / 380ms 内双击同一地点。
`_last_tap_poi` + `_last_tap_ms` 做双击判定；近处双击等同单击。
验收断言：单击矿场后 `hero_paths` 为空、面板为 true；双击后出发；到达照常弹事件。
